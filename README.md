## 🌟 Key Projects

### 1. **Git Learning** 📖
A beginner-friendly project to understand Git fundamentals and version control concepts.
- **Location:** `Assignment/git-learning/`
- **Skills:** HTML, CSS, JavaScript, Git basics
- **Status:** ✅ Completed

### 2. **ToDo Application** ✅
A full-featured todo list application for task management.
- **Location:** `Assignment/toDoApplication/`
- **Features:**
  - Add, edit, and delete tasks
  - Persistent storage with JSON
  - Task management UI
- **Technologies:** JavaScript, JSON, File System (Node.js)
- **Status:** ✅ In Development

### 3. **Node.js Server** 🖥️
RESTful API server built with Node.js exploring HTTP methods and routing.
- **Location:** `roughWork/`
- **Features:**
  - GET/POST request handling
  - JSON response formatting
  - User management endpoints
- **Endpoints:**
  - `GET /` - Home page
  - `GET /users` - Fetch all users
  - `POST /users` - Create new user
- **Technologies:** Node.js, HTTP module
- **Status:** ✅ In Development

### 4. **Classwork Projects** 📝
Collection of class assignments covering:
- JavaScript calculations and logic
- ES6 modules (type: "module")
- Node.js fundamentals
- **Location:** `Classwork/`
- **Status:** ✅ Completed

## 🚀 Getting Started

### Prerequisites
- Node.js (v14+)
- npm or yarn
- Git
- A code editor (VS Code recommended)

### Installation

1. **Clone the repository:**
```bash
git clone <repository-url>
cd "Backend College"
```

2. **Navigate to a project:**
```bash
cd Assignment/toDoApplication
# or
cd roughWork
```

3. **Install dependencies (if any):**
```bash
npm install
```

4. **Run a project:**
```bash
node server.js
# or
node toDo.js
```
